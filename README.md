# WoollyJoy Website

## Setup
1. Replace `91YOURNUMBER` in `src/app/page.js` with your WhatsApp number.
2. Add images in `public/images/`:
   - logo.png
   - hero.png
   - craft.jpg
   - box.jpg
   - bunny.png
   - teddy.png
   - piggy.png
   - frog.png
   - bee.png
   - duck.png

## Run locally
```bash
npm install
npm run dev
```

## Push to GitHub
```bash
git init
git add .
git commit -m "Launch WoollyJoy website"
git branch -M main
git remote add origin https://github.com/iamanmolnigams/WoollyJoy.git
git push -u origin main
```

## Deploy
Import the GitHub repo in Vercel and deploy.
